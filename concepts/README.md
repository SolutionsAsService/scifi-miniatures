# Vigil support vehicles: concepts

Concept blockouts for vehicles and support assets that back up the Vigil infantry, all at 1:56 to match the 30 mm heroic troopers. None of this is print-ready: each folder holds `concept.md` (role, loadouts, sizes, part split, open questions), `concept.json`, `source/concept.py` (the blockout), renders in `images/` and a blockout STL. The owner picks which ones get designed further.

## Open question across all of them
The vehicles are true 1:56, so they're big on the table (Palisade 133 mm, Sunder 173 mm, Vesper 230 mm long). A compressed "heroic" vehicle scale is an option; see each `concept.md`.
